# Aman Singh Negi — Personal Developer Portfolio

An editorial, high-performance developer portfolio built with React, Vite, Tailwind CSS, and Framer Motion, inspired by modern minimalist and atmospheric web design aesthetics (Deep Navy `#1C1C28` and Cyan `#1EC1CB` accents).

---

## ✨ Features

- **Editorial Composition & Aesthetics**: Dark atmospheric backgrounds, frosted glass surfaces, balanced typography, and restrained cyan accents.
- **Dark / Light Mode**: Integrated theme toggle with persistence in `localStorage` and system preference detection.
- **Factual & Verified Engineering Showcase**:
  - **AIFinity** (*In Progress · Team Project*): AI-powered learning-gap and career-readiness platform (ConceptRoot AI, MistakeMap AI, SkillGap AI).
  - **DevTinder**: Developer networking platform REST API backend (11 endpoints, JWT auth, bcrypt, MongoDB & Mongoose).
  - **Bankist App**: Interactive banking simulation leveraging vanilla JavaScript and functional array methods.
- **Accreditation**: Verified badges for Hacksynergy 2026 and Anthropic AI Fluency certification.
- **Responsive Architecture**: Fully optimized across mobile (320px+), tablet (768px), and desktop (1024px+).
- **Direct Resume Access**: Direct one-click download of the authentic `Resume.pdf`.

---

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) + Custom Glassmorphism System
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm (v9 or higher)

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for Production
```bash
npm run build
```
The optimized production bundle will be generated in the `dist/` directory.

### 4. Preview Production Build
```bash
npm run preview
```
